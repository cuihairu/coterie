# Coterie 视觉基准（DESIGN.md）

> 界面实现：`apps/web/`（React 19 + Vite + Tailwind CSS 4，标准调色板）。
> 本文记录审核所依据的视觉 token 与尺寸规范，供后续界面审核（WCAG / 可访问性）作对照基准。领域/架构设计见 `docs/design.md`，二者互补。

## 1. 页面底色与面板

| 用途 | token | 色值 |
|------|-------|------|
| 页面底色 | `bg-slate-50` | `#f8fafc` |
| 卡片 / 表单面板 | `bg-white` | `#ffffff` |
| 页面边框 | `border-slate-200` | `#e2e8f0` |
| 输入框边框 | `border-slate-300` | `#cbd5e1` |

文字对比度均以 `bg-slate-50`（非纯白）为基准反推，这是本套界面早期失分的主因。

## 2. 文字层级（对 `bg-slate-50` 的对比度）

| 层级 | token | 色值 | 对比度 | 用途 |
|------|-------|------|--------|------|
| 主文字 | `text-slate-900` | `#0f172a` | 15.9:1 | 标题、正文主体 |
| 标签 | `text-slate-700` | `#334155` | 9.6:1 | 表单 label、legend |
| 次要 / 元数据 | `text-slate-600` | `#475569` | 7.1:1 | 时间戳、元数据、空态、导航链接 |
| 弱化（白底卡片内） | `text-slate-500` | `#64748b` | 4.6:1（on 白） | 登录页副标题等 |
| 占位符 | 浏览器默认 | — | — | 输入 placeholder，仅作示例提示 |

**规范：12–14px 文字在 `bg-slate-50` 上不得低于 4.5:1（WCAG AA）。** 次要文字用 `text-slate-600`（7.1:1），禁止使用 `text-slate-400`（2.63:1，对 slate-50 不达标）。

## 3. 危险 / 破坏性文字（对 `bg-slate-50` 的对比度）

| 用途 | token | 色值 | 对比度 |
|------|-------|------|--------|
| 错误 / 加载失败文字 | `text-red-800` | `#991b1b` | 7.8:1 |
| 破坏性操作（退出共享圈等） | `text-rose-800` | `#9f1239` | 7.6:1 |
| 破坏性实心按钮 | `bg-rose-700` + 白字 | `#be123c` | 4.8:1 |

**规范：错误与破坏性操作是「绝不能被看漏」的信息，文字色不得低于 4.5:1。** 禁止 `text-red-600`（2.99:1）与 `text-rose-700`（3.89:1）直接置于 `bg-slate-50` 页面底。

## 4. 主操作

| 用途 | token |
|------|-------|
| 主按钮 | `bg-emerald-700` + `text-white`（`#047857`，对白 5.6:1） |
| 主按钮 hover | `bg-emerald-800` |

## 5. 触控尺寸（WCAG 2.5.8）

- 顶部导航链接 / 退出按钮：**≥24px 高**（`py-1` 使 text-sm 行高 20px 增至 28px）。
- 行内文本链接（如「← 返回圈列表」「举报此圈」）为信息性小目标，按信息性记录，不强制加高。
- 表单输入 / 选择框：`px-3 py-2`（高约 36px）。

## 6. 动效

- 当前全站无 CSS 动画 / 过渡（`anim=0`）。Operate 模式静态可接受。
- 若后续加入过渡（Tab 切换、模态出现），须同时实现 `prefers-reduced-motion` 降级。
